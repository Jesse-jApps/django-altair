# Contributing

Open an issue to discuss substantial behavior changes. Keep pull requests focused
and include a reproduction or regression test for a bug fix.

Run the tests described in the README before opening a pull request. CI checks
must pass, and review discussions must be resolved before merging. Changes go
through pull requests; do not push directly to the default branch.

Never commit credentials, private datasets, device logs containing personal
information, or generated environments. See SECURITY.md for private reports.
