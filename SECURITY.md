# Security policy

## Supported code

Security fixes target the current default branch. Historical releases and
older branches are not maintained unless a release note explicitly says otherwise.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Jesse-jApps/django-altair/security/advisories/new)
to report a suspected vulnerability privately. Include the affected version or
commit, a minimal reproduction, and the impact. Do not include real passwords,
access tokens, private keys, or personal device data.

Do not report an undisclosed vulnerability in a public issue. There is no
guaranteed response or remediation time.
